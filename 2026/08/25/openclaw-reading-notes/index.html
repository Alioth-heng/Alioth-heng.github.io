《零基础玩转 OpenClaw》读书笔记：如何把 AI 从"会聊天"养成"会干活"的数字员工
Published in：2026-08-25 | category： 读书笔记 AI 工具

书名：《零基础玩转 OpenClaw》
作者：向安玲 / 张诗瑶 / 张亚男
出版社：中信出版集团（2026 年 4 月）
一句话定位：一本从安装到精通、从配置到安全治理的 AI 代理（Agent）实战手册。

2026 年初，全球开发者社区被一个叫 OpenClaw（中文圈昵称”龙虾”）的开源项目刷屏：三个月内 GitHub 星标从 0 冲到 20 万+，硅谷投资人说”这是 AI 的下一个阶段”，OpenAI 甚至官宣收编了其创始人。火出圈的不是又一个大模型，而是因为它第一次让 AI 从”会说话的顾问”变成了”真正会干活的员工”。

这本书不讲 AI 原理、不炫技、不卖赚钱神话，只讲实实在在的场景、方法和边界。下面是我读完后梳理的重点。

一、OpenClaw 到底是什么？

传统 AI（ChatGPT / Claude / DeepSeek）像个百科全书式顾问：你问它答，问完就结束，不记得上次聊了什么，更不能主动帮你操作电脑。

OpenClaw 不一样。它运行在你本地电脑上，能：

  • 操作浏览器、管理文件、处理邮件
  • 定时执行任务、跨平台联动、批量处理重复工作
  • 持续学习并模仿你的习惯

一句话：AI 终于从”会说话”变成了”会干活”。

命名小趣闻：它最初叫 Clawdbot（Claude 谐音梗），因侵权官司改名为 Moltbot（龙虾蜕壳 molt），最终定为 OpenClaw——Open 代表完全开源、数据你掌控，Claw 保留”会干活”的龙虾主题。社区里用户互称”养虾人”，线下聚会有人穿龙虾 T 恤，Discord 里全是龙虾表情包。”养龙虾”这个说法，正是因为：你安装它、配置它、教它做事，它越用越懂你。

二、三大核心能力：从”会说”到”会做”

OpenClaw 之所以能干活，靠的是三种可组合的能力：

1. 操作电脑（Computer Use）

基于 Anthropic 2024 年推出的 Computer Use API，OpenClaw 把它开源化、本地化。它可以：

  • 控制浏览器：打开网页、点击、填表、截图、下载
  • 操作终端：运行命令、执行脚本、查看日志
  • 管理文件：读写文档、整理文件夹、解压
  • 调用 API：连接 Gmail、Google Calendar、GitHub、飞书等任何有接口的服务

2. 长期记忆（Long-term Memory）

传统 AI 每次对话结束就像失忆。OpenClaw 有两层记忆：

  • SOUL.md（灵魂文件）：你对它的永久认知——你的职业、偏好、禁忌、沟通风格。手动配置，它每次思考前都会注入。
  • MEMORY.md（记忆文件）：使用过程中自动学习的事实——老板的邮箱、每周一的团队会、你关注的股票。第一次说”发邮件给老板”它会问邮箱，第十次已经知道你是谁、用什么语气。

3. 主动行动（Proactive Action）

传统 AI 是被动的，你不问它不说。OpenClaw 可以主动行动，来自三个机制：

  • 定时任务（Cron Jobs）：每天 8 点推日程、每小时查股价、每晚 11 点备份
  • 事件触发（Event Triggers）：收到”紧急”邮件立即通知、股价跌超 5% 自动预警
  • 心跳机制（Heartbeat）：默认每 30 分钟自动唤醒一次，读 HEARTBEAT.md 清单，判断有无要处理的事——让工具变成”一直帮你盯着事情的助理”

三者组合，才造就了真正的 24 小时数字员工：你没发一条指令，它却完成了十几项工作。

三、核心架构：四件套形成自生长闭环

OpenClaw 的架构可拆成四部分，形成”下指令→中枢分发→技能执行→记忆更新→大脑反思改进”的闭环：

模块 角色 说明
Gateway 大脑指挥部 WebSocket 服务器（默认 127.0.0.1:18789），接收飞书/微信/Telegram 等所有渠道消息，解析意图、路由任务、回传结果，多通道并行互不干扰
Skills 工具箱 官方 ClawHub 有上万个现成技能，也可自己写；一个 Skill 能调用另一个 Skill 形成链条
Memory 记忆系统 SOUL.md + MEMORY.md + 可选 LanceDB 向量库，越用越懂你
Agent Brain 反思与自生长 每次执行完跑”反思循环”，自动更新记忆、建议优化 Prompt、生成新 Skill 草稿、自我修复 Bug

社区有句话很贴切：“第一周你在教它，第二周它开始帮你想，第三周它开始优化自己。”

四、版本怎么选？生态已经百花齐放

围绕 OpenClaw 形成了丰富生态，按需求对号入座：

  • 原生 OpenClaw（openclaw.ai）：官方版，数据全程本地、自定义空间最大，长期最优解
  • Kimi Claw：月之暗面云端浏览器版，免安装、中文强，但数据过云端
  • 有道 LobsterAI：网易双击安装桌面客户端，国产模型适配好、沙箱安全
  • 飞书妙搭 / WorkBuddy：字节/腾讯零配置方案，开箱即用，但定制有限、数据在云端
  • ZeelinClaw：可挂本地免费模型，零成本养虾
  • MaxClaw：稀宇科技优化分支，低配笔记本也能流畅跑
  • 云托管版（阿里云/腾讯云/扣子等）：电脑不能常开时的选择，约 15 分钟上线

关键结论：底层架构高度一致，学会一个版本，Prompt 模板和核心技能几乎可直接复用。

五、落地第一步：安装与配置

安装前想清楚三件事

  1. 操作系统：有 Mac 用 Mac（原生支持最完善），没有用 Windows（WSL2 接近原生），程序员才考虑 Linux
  2. 聊天入口：国内推荐飞书，国外首选 Telegram，新手也可先用自带 Web UI
  3. 本地还是云端：先本地（隐私最安全、成本最低），用顺了再考虑云端 24 小时运行

Mac 本地安装五步（10 分钟搞定）

六、Onboard 仪式：让龙虾”认主”

装好只是第一步，要让它从”陌生 AI”变成”私人助手”，关键在配置两个”灵魂文件”：

  • SOUL.md = 宪法：定义性格、做事风格、行为边界（主动还是等确认、简洁还是详细、什么不能做）
  • USER.md = 情商档案：记录你的时区、工作习惯、偏好

OpenClaw 的目录结构被设计成一套浪漫的”数字人生命系统”：

  • agents/ 大脑、cron/ 生物钟、extensions/ 社交触角、tools/ 小钳子
  • workspace/ 是”内心世界”：knowledge（知识库）、MEMORY.md（长期记忆）、skills（技能包）、IDENTITY.md（身份证）、SOUL.md（灵魂）、HEARTBEAT.md（心跳任务）、USER.md（社交）

新手只需先配 SOUL.md 和 USER.md。其他文件可随需求慢慢完善。升级前务必备份这两个文件——它们是花时间调教出来的，丢了只能重来。

七、基础技能：自然语言就是命令

  • 三大基础工具箱：网页搜索（Brave / 火山云融合搜索，国内可用）、文件读写、Exec 工具（在终端执行命令，监控服务器、跑脚本、管 Docker）
  • 指令技巧：说清输出格式、提供上下文、限定范围、复杂任务分步骤说
  • ClawHub 技能库：截至 2026 年 3 月超 23,000 个技能。安装 clawhub CLI 后 clawhub install <技能名> 即可，装完即时生效
  • ⚠️ 安全安装铁律：2026 年初曾发生 “ClawHavoc” 安全事件（341 个恶意技能被清除）。务必遵循 “1000/3 原则”——下载量超 1000、上线超 3 个月、有明确作者和源码链接；名称与知名技能只差一两个字母的、索要宽泛权限的、SKILL.md 为空的都别装

八、进阶玩法：把龙虾进化成超级员工

  1. 自定义 Skills（让龙虾自己造工具）
    一个 Skill 最小只需一个 SKILL.md（元数据 + 工作指南），放进 ~/.openclaw/skills/ 即可。最酷的是”递归自生长”：你告诉它需求，它写工具；工具让它更强，就能造更好的工具——让 AI 给 AI 写工具。还能用 skill-seekers 把 API 文档/官网几分钟内转成标准 SKILL.md。

  2. 长期记忆升级：向量数据库 + 多 Scope 隔离，告别健忘

  3. 多 Agent 协作：用 AGENTS.md 配置专属 Agent（如工作 Agent、个人 Agent），各司其职、自动路由

  4. 成本与模型路由：本地模型（Ollama）+ API 模型智能切换，贵任务用强模型、简单任务用便宜模型

  5. 安全边界与权限控制：沙箱模式限制操作目录、Exec 工具开启审批模式、删除文件前强制确认

九、五个真实实战案例（第六章精华）

技能包 面向人群 解决什么
vibecoding-workflow 程序员 氛围编程五阶段：需求→架构→代码→调试→迭代，每个阶段有清晰产出
github-manager 开发者 仓库管理、更新日志、CI/CD 监控、故障追踪全自动，关键决策主动推送给你
second-brain 知识工作者 快速捕获→自动整理→语义检索→知识图谱→间隔复习，本地知识管理闭环
content-intel 内容创作者 每天扫描热榜、筛选适配话题、生成多平台定制脚本
social-cli 自媒体 一键发布、数据拉取、评论区智能处理、全平台变现汇总

贯穿所有案例的一条线索：OpenClaw 负责执行，你负责决策。 它不替代你的判断，只承接判断之外所有机械、重复的执行性工作，并在每个需要人工决策的关键节点等你拍板。一句核心设计原则：“AI 绝不自作主张，只执行你明确审核通过的内容。”

十、我的几点收获

  1. 范式变了：AI 的下一阶段不是更大的模型，而是更有用的代理（Agent）。从”你问它答”到”你定规则、它持续执行”。
  2. 越用越值钱：它的价值不在开箱即用，而在你持续调教——记忆、技能、行为都在迭代，像养宠物一样越养越贴心。
  3. 安全是前提：开源 + 强权限意味着风险并存。权限最小化、先审查后使用、明文不存密码，是底线。
  4. 成本可控：会用工具的人很多，会安全、高效、低成本用工具的人不多。模型路由 + 指令优化 + 会话清理，能省下大量 token。
  5. 你才是主角：OpenClaw 替代的是执行，不是判断、创造、关系与意义。真正无法被复制的竞争力，是那份”看到革命性工具就血脉偾张、必须当天上手”的探索欲。

写在最后：这本书提供的是一条从入门到精通、从安装到安全治理的完整路径。OpenClaw 的世界很大，这本书只是个开始。但正如序言所说——“会用工具的人很多，会安全、高效地用工具的人不多。” 希望读完的你，成为后者。
